# Авторский синтетический набор v2

40 dev (20+/20−, 16 изображений), 80 final test (40+/40−, 32 изображения). Test создан после core-freeze.json. Каждая строка — отдельный авторский текстовый шаблон, без повторного использования dev-шаблонов с заменой кода. В test четыре QR-изображения (2+/2−), восемь поворотов 90/180°, четыре мелких сжатых изображения. Домены, кампании и идентификаторы семейств test не пересекаются с v1 и dev-v2.

Файлы *-annotations.jsonl отделены от входов. Анализатор получает материалы и собственные страницы из *-pages.json; метки читаются оценщиком после сохранения предсказаний. Изображения созданы Pillow из авторских текстов, QR — OpenCV; эталон OCR не передается распознавателю. В QR-примерах ocr_reference содержит напечатанный текст без декодированного URL.

separation-audit.json содержит проверку доменов, семейств, уникальности текстов и ближайшие совпадения с предыдущими наборами. Максимальная строковая близость к старому материалу 0,6818. Это не доказательство семантической независимости: классы сценариев повторяются, автор и метод создания общие. Метки не проверялись независимыми экспертами.

Положительные недоступные ссылки обозначают намерение авторского сценария; наблюдаемых данных может быть недостаточно. Такие отказы входят в FN общего recall. Отрицательные неоднозначные случаи означают отсутствие продвижения в доступном авторском материале, а не доказанную безопасность назначения.

Все URL .test обслуживаются синтетическим транспортом, денежных операций и внешних запросов нет. Материалы не представляют реальных людей или организации. Данные после первого итогового прогона защищены data-freeze.json; дальнейшие исправления потребуют новой версии.
