# Context v3: диагностический dev

52 авторских синтетических случая: 26 продвижений и 26 альтернатив; 24 контрастные пары и 4 недоступных назначения. Русский, казахский и смешанный текст. 36 случаев с URL, 16 только с текстом. Изображений нет: этот набор проверяет контекст текста/страницы, а не OCR или реальную точность в соцсетях.

Подготовлен до изменения rules-2.0. Используется для разработки rules-3; результаты после настройки не являются независимой финальной оценкой. Финальный v2 не меняется. Связанные пары намеренно находятся внутри dev; они не могут переходить в будущий final. Разметка выполнена автором набора, без независимой экспертизы. Отрицательные примеры содержат игровые слова и рекламные призывы, но имеют другой смысл.

Входы, HTML и разметка раздельны. Pipeline получает только материалы и транспорт с HTTP-ответами; поля truth/category/family/rationale не передаются. IDs и домены — нейтральные хеши; DEMO встречается у обоих классов. Предсказания записываются до чтения разметки. Порог высокого приоритета 65; недоступные положительные случаи входят в FN общего recall. Все исходники и данные хешируются при запуске, исходники архивируются. Публикуются варианты keywords, text, full; text здесь не оценивает OCR.
