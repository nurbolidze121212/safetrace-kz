## Реально запущенные проверки

- Backend: `python -m pytest -q` — **39 passed**, 8,25 с; `technical/backend-tests.txt`. Валидация, реальные пиксели OCR, цитаты, контекст/веса, разные материалы, scope, SSRF initial/redirect/rebinding, pinning, лимиты/цикл/схождение, retry 401/403/503, провайдер/кэш/схема, экспорт/секреты/HTML, persistence/recovery, replay и split leakage.
- Ruff format/check — пройдено. `pip check` — конфликтов нет.
- Frontend typecheck, ESLint, production build — пройдены. Предупреждение Vite: единый JS chunk около 699 kB (220 kB gzip), главным образом Cytoscape; локальному запуску не мешает.
- Чистое отдельное окружение `.venv-setup-check`: setup заново установил lock-зависимости, проверил модели и собрал frontend; exit 0. Реальный OCR отдельно: 1 passed, 14,98 с (`technical/clean-ocr-test.txt`). Использовался локальный кэш моделей, не чистый второй компьютер.
- Offline: `scripts/offline_check.py` блокирует socket.create_connection/getaddrinfo/socket.connect до импорта OCR. Свежий OCR без content cache, три синтетических наблюдения, решение и ZIP прошли, попыток сети 0. `technical/offline-check.json`. Это герметичная проверка приложения, не отключение сетевого адаптера Windows.
- Реальный сервер остановлен и запущен `start.ps1 -Offline -Background` без нового окна. В двух случаях сохранились решения, комментарии, OCR и индексы 80/5. Browser reload подтвердил историю. JSONL-импорт с картинкой дал 70.
- Работающий API: новость — completed/5; неразрешимый адрес — partial/недостаточно данных; Gemini без ключа — partial с local fallback. `technical/edge-cases.json`.

## Существенные пределы

- Precision 93,75%, recall 75%, FPR 5% на N=80 синтетических случаев. Независимого реального теста нет. Семейства дают зависимые пары; Wilson может быть оптимистичен.
- Слабые KK-учебные/противоречивые контексты и транслит; четыре положительных недоступных назначения. Ошибки сохранены.
- OCR не гарантирует символы URL/кодов; поворот 90° неудовлетворителен без коррекции ориентации.
- Gemini реализован и проверен с mock SDK; живого вызова нет без ключа. Live-запрос к внешнему разрешенному домену не выполнялся; защиты проверены контролируемыми тестами.
- Системный DNS resolver без собственного жесткого дедлайна. Для пилота нужен egress-service. Произвольный JS и сложные сокращатели не поддерживаются.
- Проверены Windows/Python 3.12/CPU. Linux, Python 3.11 и GPU отдельно не проверялись.
- Локальный MVP без многопользовательской авторизации. QR/видео/автоматическое сравнение двух маршрутов остаются расширениями; история наблюдений сохраняется.
