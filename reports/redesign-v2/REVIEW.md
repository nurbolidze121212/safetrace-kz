# Независимый аудит и React-проверка

Источник: примененный design-review, обязательный in-host source audit. [single-model] Внешний Claude CLI отсутствует в PATH; внешняя проверка не заявляется. Подагент design_consistency выполнил только чтение исходного frontend.

Подтвержденные исходные дефекты: ошибки формы за scrim; отсутствие перехода evidence → оригинал; нефокусируемый JSONL label; replaceState без Back/Forward и прямого #evaluation; мелкий граф без исходного узла в списке; мелкая типографика и placeholder 3.88:1; неполные ARIA tabs и возврат фокуса; недостаток данных с оформлением среднего риска.

Новая реализация: ошибки внутри формы, native dialog с возвратом фокуса, JSONL через кнопку, hashchange-навигация, клавиши стрелок/Home/End для tabs, оригинал с OCR SVG-полигонами, отдельный нейтральный insufficient. Граф загружается только при открытии вкладки. Стабильный ключ графа не пересоздает Cytoscape при одинаковом ответе опроса. Таймеры, ResizeObserver и экземпляр графа очищаются.

React-best-practices: применены разделение компонентов, динамический импорт тяжелого графа, независимые запросы при старте, защита от stale responses после unmount/смены случая, эффекты с cleanup. Никаких новых UI-зависимостей или сетевых шрифтов; интерфейс остается офлайн.

Повторный аудит обнаружил пять дефектов: скрытые доступные имена в компактной навигации; потеря черновика решения при смене вкладки; неверное разрешение material-id в маршруте; несовпадающие индексы выбранного пути; поздний ответ операции для другого случая. Все пять исправлены. Имена заданы aria-label, Decision остается смонтированным в скрытом tabpanel, material_id берется из узла графа, индекс пути ограничивается один раз, ответы применяются с проверкой текущего hash и поколения запросов. После изменения случая быстрый polling запускается заново.

2026-10-21: ESLint, tsc/Vite production build и четыре проверки ветвей пройдены. В браузере проверены черновик при переходе Решение → Маршрут → End, Home, Back/Forward; доступные имена при 980 px; кнопка исходного материала; OCR evidence → оригинал с фокусом на нужном полигоне; увеличение изображения 150% и возврат к вписанному виду. Подробнее — BROWSER_CHECK.md.
