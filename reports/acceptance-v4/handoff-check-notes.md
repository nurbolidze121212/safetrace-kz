# Уточнения процедуры передачи

Ядро, final-данные и официальные предсказания во время передачи не менялись.

- При подготовке главного демо проверяющий скрипт сначала ожидал `completed` от остановленного OCR-адреса. Фактический корректный статус — `partial`; после исправления ожидания тот же случай продолжен через `--existing`, без удаления/повторного создания и без изменения продукта.
- В первой репетиции измерен клик «Экспорт», но наличие файла ещё не было подтверждено. Загрузка повторена через browser `waitForEvent('download')`; полученный файл проверен по manifest, оригиналу, истории и HTML-якорям. 51,628 с относится к навигации и команде экспорта, не к отдельно измеренному завершению скачивания.
- Первое сравнение API после переноса отличалось только `graph.generated_at`: это время сборки ответа на каждый запрос. Проверка теперь исключает только это поле и сравнивает весь остальной документ/граф. Отдельно все сохранённые SQLite-строки и оригиналы сверены без исключений.
- Candidate содержит версию вспомогательного проверяющего скрипта до этого уточнения. Продукт и его runtime не менялись. Финальный выпуск содержит исправленный проверяющий скрипт и квитанции переноса.
- Комплект не включает скрытые окружения, ключи, рабочие модели и данные в архиве исходников. Данные находятся в отдельной резервной копии; OCR-модели устанавливаются по закреплённым SHA-256.
