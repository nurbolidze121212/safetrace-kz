# SafeTrace KZ — план и приемка

1. **A / техническая проверка.** Python 3.12 venv, реальный PaddleOCR на русском/казахском изображении, контролируемая цепочка HTTP/HTML, проверенный SDK Gemini. Приемка: сохраненные результаты эксперимента; отсутствие ключа не блокирует локальный режим.
2. **B / вертикальный процесс.** FastAPI, SQLite, очередь с восстановлением, оригиналы/OCR/признаки/маршрут/индекс/решения/ZIP, React. Приемка: новый текст и изображение проходят анализ и сохраняются после перезапуска.
3. **C / доказательные связи.** Cytoscape, scoped referral matching, источники ребер, предупреждения и ошибки. Приемка: второй материал связан только обоснованным идентификатором; SSRF и разрыв маршрута проверены.
4. **D / измерение.** 40 dev + 80 test, >=30 изображений, раздельные семейства/домены, фиксированные веса, три варианта. Приемка: реальные JSON/CSV, интервалы Wilson, coverage, p50/p95, ошибки и ограничения в UI.
5. **E / демонстрация.** Typecheck/lint/backend/build, настоящий браузер, Windows setup/start, offline и перезапуск, экспорт, пятиминутный питч. Приемка: воспроизводимые команды и доказательства фактически выполненных проверок.

Следующий этап начинается после исправления ошибок основного сценария. Публикация, платные ресурсы и удаленный репозиторий не предусмотрены.
