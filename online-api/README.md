# Ограниченный публичный обход URL

Это отдельная экспериментальная функция для онлайн-демо, **не часть измеренного Track 2 классификатора v5**. Она читает максимум четыре HTTP-перехода, до 128 KiB HTML/текста на конечной странице, с тайм-аутом 4 с на переход. Каждый домен разрешается отдельно; соединение закрепляется за проверенным публичным IPv4. Локальные адреса, IP-литералы, пользовательские порты и учётные данные в URL отклоняются.

Вывод «страница прочитана» означает только, что получен текстовый ответ. Функция не исполняет JavaScript, не проверяет вирусы, реестр лицензий или полный контент, не скачивает изображения. Для SPA и защищённых сайтов результат будет неопределённым. Временное ограничение на число запросов по IP хранится в памяти отдельного экземпляра функции и не является глобальным лимитом. Пользовательские адреса не сохраняются приложением; платформа хостинга может вести свои служебные журналы.

Проверка: `node --test` в этом каталоге. Публичный адрес функции: `https://safetrace-kz-url.vercel.app/api/check-url` (проект Vercel `fleet-savanna-fmsfxxt`, Hobby). 25 октября 2026 живой POST для `https://www.wikipedia.org/` вернул HTTP 200, одну записанную страницу и `destination_verified: true`; POST для большого текста `https://en.wikipedia.org/wiki/Casino` вернул `truncated: true`, не потеряв частичный результат. CORS preflight для GitHub Pages вернул 204. GitHub-автодеплой для отдельного проекта пока не подключён: изменения в этом каталоге сами по себе не обновляют уже развёрнутую функцию. Если сервис недоступен, браузерная форма должна оставаться честным анализом строки адреса.
