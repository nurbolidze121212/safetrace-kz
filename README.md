## Запуск

С установленным Docker, из папки проекта:

```sh
docker compose up --build -d
```

Откройте **http://127.0.0.1:8765**. Первая сборка скачивает зависимости и OCR-модели. [Параметры, данные, остановка и статус проверки контейнера](docs/DOCKER.md). Без Docker: [установка Windows](docs/INSTALL_AND_TRANSFER.md).

## Что можно показать

- Новый текст, URL или изображение → настоящий OCR/QR → причины индекса и сохранённые источники.
- Маршрут через посредника; для каждой стрелки видны способ получения и наблюдение.
- Общая сеть нескольких случаев: материалы, заявленные аккаунты/каналы, URL, домены и идентификаторы; компоненты связности и группы Louvain.
- Контрпример с предупреждением, ручное решение и ZIP-досье с оригиналами, HTML, JSON и хешами.
- [Telegram JSON и SRT с таймкодами](docs/IMPORT.md): до 1000 сообщений, пакеты по 20, ожидание очереди и квитанции.

**Онлайн:** постоянная статическая демонстрация сохранённых учебных результатов. **Локально:** обработка новых материалов, своя база и ограниченные запросы к разрешённым сайтам. [Матрица возможностей](docs/LOCAL_AND_ONLINE.md).
