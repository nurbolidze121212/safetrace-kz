# SafeTrace KZ · backend 2.1

Локальный инструмент аналитика для трека 2 «Скрытая игра» SafeNet KZ. Материал → OCR → признаки → ограниченная проверка переходов → доказательный граф → ручное решение → досье.

Индекс 0–100 определяет приоритет проверки. Это **не вероятность преступления**, не установление авторства и не юридическое заключение.

Текущая конфигурация анализа — **rules-3.0 / pipeline-2.1**. Исправлены очередь, отмена/повтор, целостность оригиналов, частичные маршруты, кодировки страниц, нормализация URL и точность облачного ввода. Контекст проверяется отдельно для материала и назначения; индекс связан с конкретным материалом. HTML-досье содержит читаемое резюме, наблюдения и переходы от оснований к цитатам.

Новый итоговый набор: **80 авторских синтетических случаев, 32 изображения**. Полный процесс: precision **96,97%**, recall **80%**, FPR **2,5%**, покрытие **86,25%**. Одиннадцать случаев без достаточных данных; семь положительных отказов входят в FN. Точечные ориентиры достигнуты на этом наборе, но интервалы широкие и независимой экспертной проверки нет. [Подробная оценка v3](reports/EVALUATION_V3.md), [протокол](reports/V3_EVALUATION_PROTOCOL.md), [ограничения и данные](docs/DATASET.md).

## Запуск на этом компьютере

Откройте PowerShell:

```powershell

powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

Откройте **http://127.0.0.1:8765**. Один FastAPI-процесс раздает собранный React и API. Остановка — Ctrl+C. База и оригиналы остаются в `data/`.

## Проверка перед показом

```powershell
.\.venv\Scripts\python.exe scripts\preflight.py --server
```

Если сервер еще не запущен, уберите `--server`. Проверка сопоставляет 94 версии Python-пакетов с lock-файлом, хеши моделей, исходники и файлы frontend, читает SQLite через соединение только для чтения. `--server` дополнительно сверяет версии уже запущенного localhost API. При ошибке выводится конкретное действие; код выхода — 1. OCR и внешние запросы не запускаются. Это проверка установки, не замена приемки или измерения качества.

После изменения frontend выполните `npm.cmd --prefix frontend run build`: сборка сохраняет отпечаток исходников и выходных файлов. Поврежденная или устаревшая сборка не проходит проверку. Отчет можно сохранить через `--report reports/preflight-local.json`.

## Первый сценарий

1. «За обещанием бонуса» → «Проанализировать». В публикации нет слова «казино».
2. «Маршрут»: HTTP 302 → страница посредника → видимая HTML-ссылка → синтетический игровой ресурс.
3. Создайте «Второй след» либо добавьте материал с адресом `https://go.safetrace.test/r/second`.
4. В графе откройте «Совпадение идентификатора»: публикации и наблюдение общего `ref=QALA7`.
5. «Похожее ≠ продвижение» показывает предупреждение с похожими словами и тем же URL.
6. Сохраните решение и скачайте «Экспорт». ZIP содержит читаемое HTML-досье с переходами от оснований к цитатам и материалам, полный JSON, оригиналы и manifest. Распакуйте весь ZIP перед открытием report.html; исходные текстовые файлы имеют кодировку UTF-8.

Все `.test`-страницы — **синтетические данные** из `fixtures/pages.json`. Транспорт не открывает сокеты. Редактирование текста страницы в этом файле меняет результат следующего анализа. «Повтор» открывает заранее сохраненный результат из `fixtures/replays/`, явно помеченный как повтор; повтор не делает новых запросов.

## Собственные материалы

«Новый анализ» принимает текст, URL и PNG/JPEG/WebP. Изображение: до 8 MiB, 12 Мп, минимум 24 px. До 20 материалов в случае, 20 000 символов на материал; очередь до 8 задач, один исполнитель. Оригиналы ограничены 512 MiB. OCR не читает имя файла, подписи набора или эталонный текст. Сохраняются строки, координаты, confidence, размер и версии моделей. Смешение алфавитов и низкая оценка распознавания помечаются для проверки. Высокий confidence не гарантирует правильный URL.

Рабочие состояния: ожидает, выполняется, завершен, частично завершен, ошибка, отменен. Отмена применяется между ограниченными этапами; уже начатый OCR/HTTP-вызов может закончиться. Прерванная перезапуском задача получает статус «частично завершен» и доступный повтор.

При сложной ориентации OCR проверяет дополнительные повороты; исходные сегменты сохраняются рядом с объединенными строками. Возможное дублирование сегментов помечается для сверки. QR декодируется по пикселям, его область видна на оригинале. HTTP/HTTPS из QR проходит обычную защиту переходов; произвольное содержимое кода не исполняется. Сравнение в разделе «Маршрут» показывает изменения сохраненных ответов и переходов между анализами без новых запросов.

### JSONL

Через интерфейс можно импортировать до 20 строк (512 KiB), по одному материалу в строке:

```json
{"text":"Исходный текст","url":"https://example.org/post","source":"Заявленный источник","published_at":"2026-10-20T12:30:00+05:00"}
```

`published_at` необязателен, но обязан содержать часовой пояс. `image_id` — идентификатор предварительной загрузки через `/api/uploads`; сервер не принимает произвольные пути файлов.

Для JSONL с **локальными изображениями** используйте клиент импорта. Поле `image` содержит путь относительно папки JSONL:

```json
{"text":"Подпись","source":"DEMO · источник","published_at":"2026-10-20T12:30:00+05:00","image":"picture.png"}
```

```powershell
.\.venv\Scripts\python.exe scripts\import_jsonl.py examples\import\materials.jsonl --mode synthetic --title "Импорт с изображением"
```

Клиент загружает изображение в локальный API, заменяет путь на `image_id` и создает случай. Выход за папку пакета блокируется.

## Сеть и Gemini

Без ключа работает настоящий OCR, локальные правила, граф, решения и экспорт. Контекстные возможности правил ограничены.

Для live-переходов создайте `.env` по `.env.example`, добавьте в `SAFETRACE_ALLOWED_HOSTS` только точные имена доменов, на проверку которых у вас есть разрешение. Поддомены не наследуют разрешение. По умолчанию список пуст, поэтому произвольные адреса не загружаются. На каждом переходе проверяются схема, порт, credentials, DNS и все IP; соединение закрепляется за проверенным IP, TLS проверяется по исходному имени. Локальные/служебные диапазоны и неоднозначные формы адресов запрещены. Cookies, входы, JavaScript, ставки, платежи и исполняемые файлы не используются.

Лимиты: до 12 попыток HTTP на случай, глубина 4, до 256 KiB на ответ, до трех видимых ссылок с каждой страницы, 4 секунды socket timeout, ограниченное чтение ответа. 429/5xx и сетевые ошибки допускают один повтор в общем бюджете; 401/403 не повторяются. DNS использует системный resolver; строгий сетевой периметр и отдельный egress proxy остаются задачей пилота.

Gemini использует серверный `GEMINI_API_KEY`, `google-genai` и модель из `GEMINI_MODEL` (по проверенной документации — `gemini-3.8-flash`). Ключ вводится только локально в `.env`, **не в переписку**. Режим выбирается явно в форме. Провайдер получает до двух нормализованных PNG суммарно до 8 MiB и до 40 000 символов JSON с текстом/OCR. Длинные тексты передаются префиксами с равным доступным лимитом; неполнота каждого источника и список переданных изображений сохраняются. Текстовые материалы не расходуют лимит изображений. Ответ проходит Pydantic и проверку точного присутствия цитат именно в переданном фрагменте текста/OCR. Схема не доказывает истинность. Есть таймаут, ограниченные повторы и кэш по содержимому/версии схемы/модели. SDK-ошибки не выводят секреты. **Живой Gemini-вызов не проверен: ключа нет.** Обработан отказ и переход к локальным правилам.

## Архитектура

```text
React + TypeScript + Vite ── /api ── FastAPI
                                  ├─ SQLite: случаи, решения, кэш
                                  ├─ originals/: неизмененные загруженные файлы
                                  └─ bounded worker
                                     OCR → признаки → переходы → граф → индекс
```

`backend/analysis.py` — признаки и веса; `links.py` — сетевой и синтетический транспорт; `providers.py` — интерфейс провайдера; `ocr.py` — OCR по пикселям; `graph.py` — доказательные связи; `exports.py` — ZIP; `pipeline.py` — этапы и повторы. Решение аналитика не меняет автоматический результат или оценку теста.

Приложение предназначено для одного аналитика на локальном компьютере. Оно привязано к 127.0.0.1; не публикуйте его как многопользовательский сервер. Контроль доступа, сроки хранения и аудит администраторов описаны в дорожной карте.
