# Комплект защиты SafeTrace KZ

[SafeTrace-KZ-defense-v3.pptx](SafeTrace-KZ-defense-v3.pptx) — шесть слайдов с заметками докладчика и ссылками на локальные источники. Текст и график редактируются; снимки показывают фактический синтетический стенд. Формат 16:9, шрифт Segoe UI.

1. Задача аналитика и трек «Скрытая игра».
2. Новый QR на изображении: OCR, HTTP и HTML-переход.
3. Предполагаемое совпадение двух материалов и проверяемые источники.
4. Предупреждение как контрпример, с сохраненной цитатой.
5. Одинаковые 80 входов для трех вариантов; ограничения оценки рядом с цифрами.
6. HTML-досье, оригиналы и следующий независимый пилот.

Текст на пять минут — [PITCH](../docs/PITCH.md), последовательность живого показа — [DEMO_V3](../docs/DEMO_V3.md), вопросы — [FAQ](../docs/FAQ.md). Слайды дополняют живой показ. Измеренная локальная озвучка текста занимает 4:09; длительность выступления человека не измерялась.

Все шесть слайдов готового PPTX повторно импортированы, отрендерены и просмотрены. Проверены ZIP, исходные значения графика 30% / 37,5% / 80%, вложенная книга данных, заметки и локальные ссылки. Проверка структуры не заменяет запуск в PowerPoint: на этом этапе он не выполнялся. Результаты и PNG каждого слайда — [reports/defense-v3](../reports/defense-v3/check.json).
