# Демонстрация SafeTrace KZ v4

Версия приложения 2.2.1, rules-4.0, pipeline-2.2.1. Все показанные публикации и страницы синтетические. Подготовка выполнена реальным локальным API и OCR; сохранённые результаты не выдаются за новый запуск.

## Перед выступлением

Открыть [основной случай](http://127.0.0.1:8765/#case/e4e5424a4abc4b129c7ad5fc8636345f). Если приложение уже работает, второй процесс не запускать. Выполнить `.\.venv\Scripts\python.exe scripts\preflight.py --server`. Запуск и перенос: [HANDOFF_V4](HANDOFF_V4.md).

Исходное [изображение](../reports/acceptance-v4/browser-new-material.png) содержит перенесённый адрес `https://go.safetrace.test` + `/r/q7`. Первичный результат: частичный, индекс 0; сомнительный префикс не открыт. Ручная сверка дала индекс 80; добавление второй самостоятельной публикации — 90. Оба предыдущих анализа сохранены. Этот успех после уточнения **не включён в автоматические метрики**.

Второй материал: «DEMO. Для новой встречи открыт второй вход. Регистрируйся и забирай бонус: https://go.safetrace.test/r/second». Одинаковый ref=QALA7 имеет смысл только вместе с назначением и исходными публикациями.

| 0:35–1:20 | Открыть материалы случая. Показать оригинал, сырой OCR и «Источник адреса». Сказать, что перенос уточнён вручную, а первый результат сохранён. |

| 2:40–3:10 | Открыть [предупреждение](http://127.0.0.1:8765/#case/4016da2c3ed0481fb5c7750b717bfb10): тот же URL, индекс 0, контекст предупреждения. |

## Фактически измерено

Техническая репетиция браузером 22.10.2026: **51,628 с** от открытия подготовленной карточки до маршрута, источника связи, контрпримера, нового решения, команды экспорта и метрик. Время включает паузы инструментов и агента; исключает подготовку случаев, новый OCR и речь. Завершение фактического скачивания и байты ZIP проверены отдельно через событие загрузки браузера. Это не человеческая пятиминутная репетиция. [Пошаговая запись](../reports/acceptance-v4/browser-rehearsal.json), [проверка файла](../reports/acceptance-v4/main-demo-export/browser-acceptance.json).

Реальный новый OCR измерен отдельно: первый анализ с загрузкой модели 9,957 с; повтор с кэшем 0,196 с на этом ПК. Шесть новых изображений в очереди: ожидание 0,048–14,470 с. Эти цифры не являются обещанием пропускной способности.

## Резерв без запущенного сервера

Распаковать [фактически скачанный ZIP](../reports/acceptance-v4/main-demo-export/browser-new-case.zip) целиком и открыть `report.html`. Он содержит исходное изображение, историю 0→80→90, решение и источник каждой ссылки. Все пять файлов manifest, исходные байты и внутренние HTML-якоря проверены. Назвать его сохранённым синтетическим примером. Дополнительно открыть [слайды](../deliverables/SafeTrace-KZ-defense-v4.pptx) и [отчёт PDF](../output/pdf/SafeTrace-KZ-report-v4.pdf).

Для свежего ввода загрузить указанное изображение через «Новый анализ», выбрать «Синтетический стенд». Дождаться частичного результата, сверить обе строки адреса, выбрать предложение и оставить комментарий. Затем добавить второй материал. Не вписывать готовый OCR вместо изображения.
