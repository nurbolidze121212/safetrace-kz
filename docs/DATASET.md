# Синтетический набор v1

120 случаев: 40 dev (20 семейств × 2 варианта), 80 test (40 других семейств × 2 варианта). Всего 41 JPEG, включая небольшой шрифт, JPEG-сжатие и наклон. В финальной выборке 27 изображений. Русский, казахский и смешанный язык; прямое/скрытое продвижение, многошаговые и неразрешимые ссылки, транслит, предупреждения, новости, обучение, бесплатные игры, обычные партнерские предложения, неоднозначность.

Авторские синтетические сообщения написаны при создании проекта; эталонные классы также заданы автором. Это **не независимая человеческая экспертная разметка**. Законные независимые реальные данные не предоставлялись. Разработчик знает смысл сценариев, поэтому даже разделенный синтетический тест оптимистичен относительно неизвестной реальной среды.

`dev.jsonl` / `test.jsonl` содержат только непрозрачный ID и исходные материалы. Имена изображений, источников и доменов — нейтральные хеши без классов. DEMO присутствует в обоих классах. `annotations.jsonl` отдельно хранит truth, язык, категорию, family, эталонный текст и ожидаемое назначение. `*-pages.json` содержит только HTTP-ответы/HTML, без полей класса.

Анализатор получает входные материалы и транспорт. Не получает truth, family, category, reference_text, ожидаемый маршрут или имя изображения. Оценщик сначала сохраняет предсказания, затем читает метки.

Семейства, кампании и домены между dev и test не пересекаются. Проверка этого разделения входит в backend-тесты. Два близких варианта внутри одного семейства остаются в одной части. Это дает зависимые наблюдения: стандартный Wilson-интервал по случаям не учитывает кластеризацию, и это ограничение отмечено в отчете.

## Оценка

Три варианта получают одинаковые случаи:

1. Baseline по ключевым словам, без пикселей/переходов.
2. Текст + настоящий OCR + локальный контекст, без переходов.
3. Полный процесс с переходами и графом.

Порог = 65. Фиксация включает входные данные, изображения, метки, сетевые фикстуры, ядро, веса, модели и зависимости. Результаты — JSON и CSV. Test после фиксации не используется для изменения правил; новая конфигурация требует новой версии оценки.

TP/FP/TN/FN считаются по всем входам. Отказ на положительном случае входит в FN общего recall. Дополнительно показываются coverage и precision/recall обработанных. Precision = TP/(TP+FP), recall = TP/(TP+FN), F1 = 2TP/(2TP+FP+FN), FPR = FP/(FP+TN). Если нет предсказанных положительных, precision = null. Интервалы precision/FPR — Wilson 95%.

OCR-вариант и полный процесс выполняют OCR заново с выключенным кэшем содержимого; модели уже загружены. Время первоначальной загрузки записано отдельно. p50/p95 измеряются по фактическому wall clock. Синтетический транспорт не отражает задержки интернета. Для изображений отдельно записано сходство распознанной и эталонной строки; это вспомогательная проверка, не общая точность OCR.

Набор не содержит реальных аккаунтов или казино. Тексты и растровые карточки созданы в проекте. Шрифт Arial используется из установленной Windows, сам файл шрифта не распространяется.
