# Исследовательский baseline по тексту

Это ретроспективный эксперимент приложения 2.4 на уже известном synthetic-v4. Он не является новой независимой оценкой и не заменяет классификатор приложения.

Обучение: только текстовые материалы старых `synthetic-v2/dev` и `context-v3-dev`. URL заменены маркером, подписи источников и эталонные транскрипции не используются. После удаления повторов «нормализованный текст + метка» осталось 74 записи, 36 положительных. У 16 текстов обе метки: одинаковое приглашение может вести на разные назначения. Оба варианта сохранены. Это ограничение входа, а не повод выбрать удобную метку.

Модель: TF-IDF по символьным n-граммам 3–5, до 30000 признаков, LogisticRegression(C=1, class_weight=balanced, random_state=42), порог 0,5. Поиск параметров и подбор порога на v4 не проводились. 48 текстовых случаев v4; совпадений нормализованных сообщений с обучением не найдено. Это не исключает общих авторских шаблонов.

| Вариант | TP / FP / TN / FN | Precision | Recall | F1 |
|---|---|---:|---:|---:|
| Сохранённый keyword-baseline v4 с его проверкой достаточности | 4 / 14 / 10 / 20 | 22,2% | 16,7% | 19,0% |
| TF-IDF + логистическая регрессия | 18 / 5 / 19 / 6 | 78,3% | 75,0% | 76,6% |
| Объединение срабатываний ML и keyword-baseline | 19 / 17 / 7 / 5 | 52,8% | 79,2% | 63,3% |

Для контекста: полный исторический процесс на этих 48 случаях имеет TP20 / FP2 / TN22 / FN4, Precision90,9%, Recall83,3%, F1 87,0%. Он дополнительно читает назначения, поэтому это сравнение с другим объёмом информации. Keyword-baseline в таблице — упрощённая историческая абляция, а не текущие правила полного процесса.

Вывод ограничен экспериментом: обучаемая текстовая модель полезнее этой keyword-абляции, но простое объединение увеличивает ложные срабатывания. Оснований заменять полный процесс или обещать улучшение на реальных данных нет. Значение LogisticRegression не калибровано как вероятность опасности и не показывается в продукте.

В [JSON](../reports/release-2.4/text-baseline.json) сохранены все предсказания, языковые срезы, PR-кривая, версии и SHA-256 входов. Время обучения 0,034 с — один локальный замер, не benchmark сервера.

Повторение в отдельном исследовательском окружении:

```sh
python -m pip install -r requirements-research.txt
python scripts/research_text_baseline.py
```

Скрипт не перезаписывает существующий отчёт. Для повторения используйте отдельную копию проекта без `reports/release-2.4/text-baseline.json`; исходный результат сохраните. Веса, frozen final и production-зависимости не меняются. Следующая проверка должна использовать новые данные и независимую разметку, с заранее закреплённым протоколом.
