# How to: установить и перенести SafeTrace KZ

Результат — локальный сервер с браузерным интерфейсом на Windows. Исходники передаются отдельно от рабочей базы и ключей. Команды выполняются в PowerShell из корня распакованного проекта.

## Требования

Windows x64, Python 3.12 x64, Node.js 22.12+, ориентировочно 3 GB свободного места. Проверены Python 3.12.14 и Node 24.13.1. GPU и Docker не нужны. Python 3.11 допускается установщиком, но отдельная приёмка на нём не проводилась; Python 3.14 не подходит текущим закреплённым зависимостям. Linux/macOS не проверены.

Полный путь должен быть ASCII: например `C:\SafeTrace-KZ`. Пробелы допустимы, кириллица в пути моделей вызывает проблему у закреплённой Windows-сборки OCR. Это не ограничение русского/казахского текста.

## 1. Установить программу

Скачайте исходный ZIP репозитория или комплект 2.3.0 и распакуйте. Адрес удалённого репозитория нужно брать у фактически опубликованного проекта; ссылка на ещё не созданный GitHub не является источником.

```powershell
cd C:\SafeTrace-KZ
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1
```

Скрипт создаёт `.venv`, ставит закреплённые Python-пакеты, скачивает и сверяет модели по SHA-256, запускает `npm ci` и собирает frontend. На обычном ПК используется `py -3.12`; при необходимости указать полный путь:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup.ps1 -PythonPath 'C:\Python312\python.exe'
```

`C:\Python312\python.exe` — пример; подставьте установленный интерпретатор. Первая установка требует интернета. Копировать `.venv` с чужого компьютера вместо установки не рекомендуется; исходный комплект не является самостоятельным exe.

## 2. Запустить и проверить

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Offline -Background
.\.venv\Scripts\python.exe scripts\preflight.py --server
```

Открыть [приложение](http://127.0.0.1:8765). Preflight сверяет Python-пакеты, модели, fingerprint сборки, SQLite и версии сервера. Он не запускает новый OCR и не является оценкой точности. Затем выполнить реальный пример из [README](../README.md#первый-показ-за-три-шага).

Офлайн: OCR, правила, история, синтетический стенд и экспорт доступны; внешние страницы недоступны. Внешний разрешённый обход требует снять Offline и задать точные узлы `SAFETRACE_ALLOWED_HOSTS` в `.env`. Это не делает доступным весь интернет. `.env.example` показывает переменные; ключи Gemini для локального сценария не нужны.

## Создать переносимый исходный комплект

В рабочем Git-каталоге после сборки и фиксации выбранных файлов:

```powershell
.\.venv\Scripts\python.exe scripts\package_source.py --output deliverables\releases\2.3.0\SafeTrace-KZ-2.3.0-source.zip
.\.venv\Scripts\python.exe scripts\package_source.py --verify deliverables\releases\2.3.0\SafeTrace-KZ-2.3.0-source.zip
Get-FileHash deliverables\releases\2.3.0\SafeTrace-KZ-2.3.0-source.zip -Algorithm SHA256
```

Скрипт не перезаписывает существующий архив: для нового снимка выберите новое имя. Он включает отслеживаемые файлы текущего checkout и проверенный `frontend/dist`; новые неотслеживаемые файлы сначала нужно явно включить в Git. `PACKAGE_MANIFEST.json` записывает исходный коммит, наличие изменений, размеры и SHA-256 каждого файла. Успешный `--verify` проверяет полный список и байты. Этот внутренний manifest проверяет целостность, но не удостоверяет автора; внешний SHA-256 следует получить из доверенного канала.

Рабочая база, ключи, модели и окружения не входят. В архиве уже есть интерфейс, но Python-зависимости и модели всё равно устанавливаются через setup. Не заявлять установку на другом ПК только на основании успешной упаковки.

## 3. Перенести рабочие случаи

На исходном ПК создать новый архив с уникальным именем:

```powershell
.\.venv\Scripts\python.exe scripts\backup_data.py create --output data\backups\transfer-2.3.zip
.\.venv\Scripts\python.exe scripts\backup_data.py verify data\backups\transfer-2.3.zip
```

Передайте ZIP доверенным способом отдельно от исходников; он содержит незашифрованные материалы и историю. На новом ПК после setup, **до первого запуска**, разместите архив рядом с проектом:

```powershell
cd C:\SafeTrace-KZ
.\.venv\Scripts\python.exe scripts\backup_data.py verify ..\transfer-2.3.zip
.\.venv\Scripts\python.exe scripts\backup_data.py restore ..\transfer-2.3.zip --to data
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Offline -Background
.\.venv\Scripts\python.exe scripts\preflight.py --server
```

Существующая `data` не перезаписывается. Если приложение уже запускалось, восстановите в отсутствующую `data-restored` и выберите её через `SAFETRACE_DATA_DIR` по [BACKUP](BACKUP.md). Не удаляйте старую базу ради удобства. История и изображения входят в резервную копию; модели, окружение, ключи и несвязанные загрузки не входят.

## Остановка, обновление и откат

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\stop.ps1 -Port 8765
```

Скрипт проверяет принадлежность процесса и отказывается останавливать активный анализ. Перед обновлением создать резервную копию; хранить прежний исходный архив. Для нового frontend выполнить `npm.cmd --prefix frontend run build`, затем перезапустить сервер и preflight. Для отката использовать отдельную папку исходников и восстановленную копию данных, не перезаписывать рабочую базу.

Логи: `logs/server-8765.out.log`, `logs/server-8765.err.log`. Порт можно изменить через `-Port 8767`; одновременно два сервера не могут владеть одной папкой данных.

## Что проверять жюри

Новый OCR по картинке без текстовой подсказки; маршрут со всеми источниками; предупреждение с низким приоритетом; неполный/неоднозначный адрес; скачивание и manifest; дополнительный пассивный аудит с явно неподключёнными проверками. API-описание: `/docs`, `/openapi.json`. Результат должен сохраняться после штатного перезапуска.

## Неисправности

| Симптом | Действие |
|---|---|
| Нет `.venv` или frontend | Выполнить setup, проверить код выхода |
| Ошибка пути OCR | Перенести в ASCII-папку, установить там |
| Модель повреждена | [Процедура восстановления](MODEL_RECOVERY.md), не отключать хеш-проверку |
| Порт занят | Открыть существующий сервер либо выбрать другой порт/отдельные данные |
| База уже занята | Остановить её проверенного владельца; не обходить lock |
| Все внешние адреса недоступны | Проверить Offline и точный allowlist; посмотреть сохранённую причину остановки |
| На телефоне не открывается localhost | Этот адрес указывает на сам телефон. Для отдельного HTTPS-показа следуйте [PUBLIC_DEMO](PUBLIC_DEMO.md); физический телефон ещё не проверен |
| OCR занимает несколько секунд | Смотреть этап; первый запуск загружает модель, не отправлять материал повторно |
| Сборка не соответствует исходникам | Выполнить production build и повторить preflight |

Проверка переноса v4 выполнялась в другую папку **того же ПК** с переиспользованием окружения. Это не подтверждение чистой установки на другом физическом устройстве. Для 2.3.0 область проверки записана в [отчёте](../reports/LINK_AUDIT_2_3.md).
