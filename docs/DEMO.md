## Если что-то пошло не так

- Сначала прочитать статус и ограничения. «Частично завершен» не означает низкий риск.
- Кнопка «Повтор» на карточке открывает сохраненный анализ с явной пометкой. Сразу сказать аудитории, что это повтор; не выдавать за новый OCR/ответ модели.
- При занятом порту открыть уже работающий сервис либо использовать `-Port 8766`.
- При ошибке сети основной офлайн-сценарий продолжает работать. Live-переходы и Gemini в офлайн-режиме не выполняются.
- Не устанавливать зависимости и не запускать полный test во время выступления.
- Если сломан интерфейс, открыть HTML из заранее проверенного ZIP и таблицу `reports/EVALUATION.md`, честно обозначив сохраненный результат.
