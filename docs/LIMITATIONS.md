# Границы SafeTrace KZ

Проект расставляет приоритеты для ручной проверки скрытого продвижения азартных игр в рамках трека 2. Индекс 0–100 и уровни «низкий / средний / высокий» не являются вероятностью нарушения, юридическим заключением или подтверждением владельца сайта. При недостатке данных вывод отдельно обозначен как неполный; низкий индекс не доказывает безопасность.

- **Данные и метки.** v5 — авторский синтетический набор с родственными шаблонами и доменами `.test`. Две модели настроены на разные LLM, но их фактическую serving-идентичность и независимость ошибок нельзя подтвердить извне. Человеческой слепой разметки и полевой проверки на реальных сообщениях нет. Для скриншотов LLM получили авторскую транскрипцию, а полный процесс работал с настоящим OCR пикселей. Метрики с интервалами относятся только к этому набору.
- **Текст и изображение.** Словари и локальные правила ошибаются на новых схемах, сложных отрицаниях, иронии, плохом качестве кадра и смешении языков. Сомнительный OCR-адрес останавливается для уточнения; часть ошибок символов может не распознаться. Одноцветный кадр не проходит OCR и остаётся случаем с недостаточными данными.
- **Ссылки и сеть.** Обход в локальном режиме выполняется только с разрешённой сетью и списком допустимых адресов. Стенд `.test` не проверяет реальное зеркало казино, фактическую лицензию, владельца ресурса или репутацию. Слабые связи по похожему тексту, коду, IP и имени домена являются гипотезами, а не установленными кампаниями. Сеть не повышает индекс отдельного случая.
- **Масштаб.** Redis Streams и 1–4 CPU-воркера проверены на отдельном стенде GitHub Actions. Опубликованные числа относятся к короткой авторской нагрузке на четырёх CPU, не к ёмкости реальной платформы. Общий том SQLite ограничивает горизонтальное масштабирование; многомашинный поток потребует отдельного хранилища и новых замеров.
- **Интерфейсы.** GitHub Pages проверяет только введённый текст в браузере. Он не открывает ссылку, не делает OCR и не хранит ввод. Полный разбор и импорт доступны локально. Физический телефон не тестировался. Автоматического чтения WhatsApp/Telegram, распознавания речи в прямом эфире и антивирусного анализа нет; импортируется только подготовленный Telegram JSON или SRT.
- **Расширения.** Треки 1 и 3 измерены отдельно на малых авторских текстовых тестах и не входят в качество трека 2. Аудит других ссылочных угроз остаётся отдельным экспериментом без метрик для игорного сценария.
