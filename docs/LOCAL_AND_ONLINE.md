|---|---|---|---|

| OCR | Реальный локальный запуск | Сохранённый результат реального OCR | Реальный OCR на компьютере автора |

## Телефон

Статическая страница доступна по HTTPS в браузере и проверена на мобильной ширине 390×844. Физический телефон не использовался. Адрес `127.0.0.1` на телефоне означает сам телефон; для живого анализа нужен доступный отдельный сервер.

## Проверенные границы

24 октября выполнен живой внешний показ с OCR, картой и ZIP; это [исторический отчёт](../reports/PUBLIC_DEMO_2026_10_24.md). Старый Quick Tunnel не используется как постоянный адрес. 25 октября добавлены GitHub Pages, отдельный Vercel сервер ограниченного чтения URL и контейнер с проверкой в Linux CI. [Отчёт 2.4](../reports/RELEASE_2_4.md).

GitHub Pages не выполняет Python/OCR. Текстовая форма использует отдельные упрощённые правила JS без передачи текста серверу. URL передаётся функции Vercel; она отдельно разрешает каждый домен, читает максимум четыре HTTP-перехода и ограниченный конечный HTML/текст. Если сайт защищён, требует JavaScript, не отвечает или возвращает не текст, результат остаётся неопределённым. Сервис не проверяет вирусы, лицензии, фото и полную безопасность. Он не хранит пользовательские URL в базе приложения; хостинг может вести служебные журналы. Результаты онлайн-форм нельзя приравнивать к измеренному полному процессу v5. OCR, загрузка новых фото и полноценных досье предусмотрены в локальном приложении. [Исходник экспериментальной функции](../online-api/README.md).
