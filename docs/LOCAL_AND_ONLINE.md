# Локальная версия и онлайн-показ

| Возможность | Локальная установка / Docker | Постоянная демонстрация GitHub Pages | Временный HTTPS-стенд |
|---|---|---|---|
| Новые тексты, ссылки и фото | Да, сервер на вашем компьютере | Нет, просмотр сохранённых случаев | Да, пока сервер автора работает |
| OCR | Реальный локальный запуск | Сохранённый результат реального OCR | Реальный OCR на компьютере автора |
| Полный учебный маршрут | Синтетические `.test`-страницы | Сохранённые наблюдения и источники | Синтетические `.test`-страницы |
| Внешние сайты | Ограниченный обход при настройке сети и точного allowlist | Не открываются | Отключены на сервере |
| Сеть материалов | Строится из вашей базы одного режима | Сохранённая структурная сеть 446 сущностей | Зависит от версии запущенного стенда |
| Telegram JSON / SRT | Локальный конвертер и пакетная подача | Нет | Для основного локального режима |
| Решения и история | Своя база и файлы | Без записи | Отдельная общая база показа |
| Экспорт | Новое досье HTML/JSON/ZIP | Скачать подготовленный ZIP примера | Новое досье из отдельной базы |
| Доступность | Пока запущен ваш сервер | Без зависимости от компьютера автора | Пока работают компьютер, сервер и туннель |

Главная задача — выявлять признаки скрытой рекламы азартных игр. Link-audit — отдельный эксперимент вне основной истории трека. Ни один режим не реализует антивирус, проверку лицензий казино или универсальную репутационную базу.

## Телефон

Статическая страница доступна по HTTPS в браузере и проверена на мобильной ширине 390×844. Физический телефон не использовался. Адрес `127.0.0.1` на телефоне означает сам телефон; для живого анализа нужен доступный отдельный сервер.

## Проверенные границы

24 октября выполнен живой внешний показ с OCR, картой и ZIP; это [исторический отчёт](../reports/PUBLIC_DEMO_2026_10_24.md). Старый Quick Tunnel не используется как постоянный адрес. 25 октября добавлена статическая публикация через GitHub Pages и контейнер с проверкой в Linux CI. [Отчёт 2.4](../reports/RELEASE_2_4.md).

GitHub Pages не выполняет Python/OCR. Его результаты явно обозначены как сохранённые; загрузка новых пользовательских материалов предусмотрена в локальном приложении.
