# Локальная версия и ограниченная онлайн-демонстрация

**Основной способ использования SafeTrace KZ — установка на своём компьютере.** Она даёт доступ к реализованному рабочему процессу: добавить материал, распознать изображение, разобрать признаки, проверить доступный маршрут, открыть источники, сохранить решение и выгрузить досье. Браузер служит интерфейсом, а Python-сервер, OCR-модели и база работают на компьютере.

**Онлайн-ссылка предназначена для демонстрации части этого процесса.** Это отдельный экземпляр того же приложения с ограничениями, временным доступом и учебными данными. Он выполняет настоящий OCR, но не обращается к произвольным внешним страницам. Онлайн-демо не заменяет локальную установку для полноценной работы с собственными случаями.

Главная задача обеих версий — выявлять признаки **скрытого продвижения азартных игр**, трек 2 «Скрытая игра». Подмена домена и просьба сообщить секрет — дополнительные признаки в тех же материалах. Они не доказывают связь с казино.

## Что доступно в каждом варианте

| Возможность | Локальная установка | Онлайн-демо |
|---|---|---|
| Ввод текста, ссылки, PNG/JPEG/WebP | Доступен после установки и запуска сервера | Доступен во время работы стенда, после входа по коду |
| OCR и QR из нового изображения | Выполняются на вашем компьютере, модели устанавливаются заранее | Выполняются на компьютере автора; результат не подставляется из готового скриншота |
| Анализ текста RU/KK | Локальные правила, с известными ошибками и ограничениями | Те же локальные правила; доступность сайта не означает обращение к облачной модели |
| Произвольная ссылка из WhatsApp | Можно добавить адрес и текст. Проверка содержимого сайта зависит от режима и разрешённых узлов | Анализируются адрес и предоставленный текст/фото. Содержимое внешнего сайта не запрашивается |
| Внешние HTTP-переходы и HTML-ссылки | Только при разрешённой сети и точном списке узлов `SAFETRACE_ALLOWED_HOSTS`. В офлайн-режиме недоступны | Отключены принудительно. Переключатель в форме не снимает это ограничение сервера |
| Полная учебная карта через посредника | Доступна в синтетическом стенде на собственных `.test`-адресах | Доступна в том же учебном сценарии. Это не исследование действующих казино |
| Карта реального неизвестного сайта | Только по доступным сохранённым наблюдениям, иначе видимая остановка или неполнота | Без внешних наблюдений полный маршрут не появится |
| История, ручное решение, оригиналы, ZIP | Сохраняются в вашей базе; есть команды резервного копирования и переноса | Сохраняются в отдельной общей базе показа. Все получатели кода видят её материалы |
| Дополнительный аудит формы URL и текста | Экспериментальные признаки, свои источники и отдельный JSON | Те же пассивные проверки без новых сетевых запросов |
| Настройки, установка моделей, API-документация | Управляются владельцем компьютера; `/docs` доступен у локального сервера | Служебные страницы API закрыты, серверные настройки меняет автор стенда |
| Доступ с телефона | `127.0.0.1` на телефоне указывает на сам телефон. Для удалённого показа нужен отдельный HTTPS-стенд | Через браузер по действующему адресу и коду. Проверена мобильная ширина; физический телефон ещё не испытан |
| Доступность | Пока ваш сервер запущен. После установки модели и локальный анализ могут работать без интернета | Пока компьютер автора, сеть, сервер и туннель работают. Постоянного хостинга нет |

«Доступно локально» означает реализованную возможность в проверенном окружении. Это не обещание распознать любую картинку, понять каждую фразу или открыть любой сайт. Даже локальная версия не запускает JavaScript произвольных сайтов и не обходит ограничения доступа.

## Что произойдёт с вашей ссылкой или фотографией

**Фото с сообщением.** Вы загружаете его вручную. OCR извлекает текст; можно открыть оригинал, найденные фрагменты и причины индекса. Если адрес распознан неоднозначно, требуется сверка. Отсутствие найденных признаков не подтверждает безопасность сообщения.

**Обычная внешняя ссылка в онлайн-демо.** Сервер разбирает видимый адрес и предоставленный вами текст. Он не открывает внешний сайт. Если для вывода нужна целевая страница, её содержимое остаётся непроверенным. Объяснение не должно создавать впечатление, что весь маршрут уже исследован.

**Учебный пример с `.test`.** Собственный синтетический транспорт возвращает заранее подготовленные страницы стенда, а OCR и обработка нового входа выполняются реально. Можно показать весь путь: исходное фото, посредника, страницу с игровыми признаками, объяснение индекса и экспорт. Синтетический режим подписан в интерфейсе.

**Локальная проверка разрешённого сайта.** После отдельной настройки сети сервер может выполнить ограниченный HTTP-обход разрешённых узлов. Каждый последующий адрес также должен пройти ограничения. Это не сканирование всего интернета, а недоступные участки нельзя считать проверенными. [Сетевые границы](ARCHITECTURE.md).

## Что не реализовано ни в одном варианте

- Подключённая актуальная база репутации URL, антивирусное сканирование или исполнение подозрительного файла в песочнице.
- Автоматическое подтверждение владельца, лицензии, честности выплат или «подлинности» казино.
- Полный каталог брендов: в дополнительном справочнике пока только пример Apple.
- Автоматическое чтение переписки WhatsApp, расширение браузера или установленное мобильное приложение/PWA.
- Калиброванная вероятность «это казино» или «это мошенничество». Индекс 0–100 служит для очереди ручной проверки.

Эти ограничения не исчезают при скачивании исходников. [Подробные статусы дополнительных проверок](EXTENDED_ANALYSIS.md).

## Какой вариант выбрать для защиты

**Для полного воспроизводимого показа:** установить проект на ноутбук, заранее загрузить модели, запустить локальный сервер и подготовить собственные учебные примеры. Показать фото без текстовой подсказки, карту, источник причины, контрпример и ZIP. [Установка и перенос](INSTALL_AND_TRANSFER.md) · [Сценарий показа](MESSAGE_DEMO.md).

**Для короткого знакомства через ссылку:** автор запускает отдельный стенд, передаёт текущий адрес и код участникам. Перед показом нужно открыть ссылку и повторить загрузку учебного фото. В очереди демо использовать материалы без личной переписки: доступ к ним общий. [Запуск HTTPS-демо](PUBLIC_DEMO.md).

GitHub хранит исходники и отчёты. Наличие репозитория не означает, что Python/OCR-сервер сейчас включён.
