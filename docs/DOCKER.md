# Контейнер CPU

Нужны Git и Docker Engine / Docker Desktop с Compose. Из папки проекта:

```sh
docker compose up --build -d
```

Откройте [локальное приложение](http://127.0.0.1:8765). Первое построение скачивает Python/Node-зависимости и закреплённые OCR-модели; оно занимает несколько минут и требует интернета. После сборки анализ текста, OCR и синтетические маршруты работают без сети. Это не «установка всего за минуту».

Образ использует Linux amd64 / Python 3.12 / CPU. Compose публикует порт только на `127.0.0.1` компьютера. На ARM Mac используется эмуляция amd64; производительность на физическом Mac не измерена. Контейнер не открывает рабочую папку проекта или личную базу: его данные находятся в именованном томе `safetrace-data`.

```sh
docker compose logs -f
docker compose stop
docker compose start
```

Для остановки и удаления контейнера без удаления данных: `docker compose down`. Опция `-v` удаляет том с данными — не используйте её для рабочей базы.

Внешние страницы по умолчанию отключены (`SAFETRACE_OFFLINE=1`). Для согласованного живого исследования владелец должен отдельно настроить режим и точный список `SAFETRACE_ALLOWED_HOSTS`. Включение сети не подтверждает безопасность или законность произвольного сайта.

GitHub Actions строит контейнер, запускает его, создаёт новый текстовый случай, отправляет изображение в настоящий OCR и проверяет ZIP. [Состояние проверок](https://github.com/nurbolidze121212/safetrace-kz/actions/workflows/ci.yml). Наличие workflow не равнозначно его успешному выполнению; результат запуска указан в отчёте выпуска.
