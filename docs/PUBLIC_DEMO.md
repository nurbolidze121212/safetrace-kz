# Сайт для показа с телефона

SafeTrace можно показать по HTTPS с телефона: сайт и API обслуживает отдельный процесс на компьютере автора, а Cloudflare Tunnel передаёт запросы. Это временный демонстрационный запуск. Он прекращается при выключении/сне компьютера, остановке процессов или потере сети. Новый запуск выдаёт новый адрес и код.

## Запустить на своём компьютере

1. Выполните [обычную установку](INSTALL_AND_TRANSFER.md), включая модели OCR и сборку интерфейса.
2. Установите `cloudflared` из [официального источника Cloudflare](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/). Не требуется покупать домен или подписку для Quick Tunnel.
3. В PowerShell из корня проекта:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_public_demo.ps1
   ```

4. Откройте напечатанный HTTPS-адрес на телефоне и введите код. Адрес доступен вне домашней Wi-Fi сети. Не добавляйте код в URL, GitHub или скриншоты.
5. Для остановки выполните напечатанную команду `stop_public_demo.ps1 -Record ...`. Команда проверяет PID и время старта; личный сервер на 8765 не останавливает. Данные показа сохраняются.

Не меняйте обычный `start.ps1` на прослушивание `0.0.0.0` и не направляйте туннель на порт 8765 с рабочей базой. Публичный запуск использует порт 8770, новую папку `data/public-demo/<случайный ID>` и отдельный код доступа. Повторный запуск создаёт новый пустой стенд.

## Что доступно

Настоящее распознавание загруженных PNG/JPEG/WebP, локальные правила, разбор адресов из текста/изображения, карта по сохранённым наблюдениям, ручное решение и экспорт. Три встроенных примера используют собственный синтетический транспорт; этот факт виден в интерфейсе. Через обычный режим можно проверять текстовые признаки и форму URL.

В демонстрации принудительно включён `SAFETRACE_OFFLINE=1`: **внешние страницы не открываются, репутационные базы и облачная модель не вызываются**. Надпись «Офлайн» относится к анализу внешних источников; браузер подключён к серверу по интернету. Фишинг и вирусы не подтверждаются автоматически.

## Доступ и данные

Это общая очередь для небольшого показа: все, кому передан код, видят добавленные в неё материалы и могут оставлять решения. Это не многопользовательский сервис с личными кабинетами. Для демонстрации используйте учебные примеры без личной переписки и секретных ссылок. HTTPS-запросы проходят через инфраструктуру Cloudflare; это не сквозное шифрование до компьютера без посредника.

Сессия живёт до 12 часов: HttpOnly, Secure, SameSite=Strict cookie. Внешний Host и Origin проверяются; без входа API и файлы недоступны. Лимиты на минуту общие для стенда: 20 попыток входа, 30 изменяющих запросов, 1200 чтений. Лимиты загрузки и очереди остаются серверными: 8 MiB/изображение, 12 Мп, 512 MiB оригиналов, до 8 активных задач. Многопользовательские квоты, плановое удаление и гарантии доступности пока отсутствуют.

Конфигурация с кодом и ключом сессии сохраняется только в игнорируемой Git папке `logs/`. Рабочая база не копируется. Менять код следует новым запуском; это также отделит новые учебные материалы от прежних.

## Проверка и перенос

```powershell
.\.venv\Scripts\python.exe -m pytest tests\test_demo_gateway.py -q
.\.venv\Scripts\python.exe scripts\check_public_demo.py
```

Первая команда проверяет границу доступа; вторая запускает настоящий OCR и экспорт через gateway в изолированном ASGI-тесте. Она **не проверяет интернет-соединение**. Внешнюю ссылку нужно отдельно открыть в браузере, загрузить учебное фото и дождаться результата. После переноса повторите проверку на новой машине.

Для постоянного круглосуточного сайта следующий этап — сервер с постоянным диском и фоновым worker, полноценная авторизация, отдельные данные пользователей, HTTPS-домен, резервирование и мониторинг. Один GitHub Pages или статический Vercel frontend не запускает текущий Python/OCR/SQLite backend. До этого этапа временный туннель не следует представлять как постоянный хостинг. [Документация Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
