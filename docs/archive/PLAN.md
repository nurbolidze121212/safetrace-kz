# SafeTrace KZ — план и приемка

1. **A / техническая проверка.** Python 3.12 venv, реальный PaddleOCR на русском/казахском изображении, контролируемая цепочка HTTP/HTML, проверенный SDK Gemini. Приемка: сохраненные результаты эксперимента; отсутствие ключа не блокирует локальный режим.
2. **B / вертикальный процесс.** FastAPI, SQLite, очередь с восстановлением, оригиналы/OCR/признаки/маршрут/индекс/решения/ZIP, React. Приемка: новый текст и изображение проходят анализ и сохраняются после перезапуска.
3. **C / доказательные связи.** Cytoscape, scoped referral matching, источники ребер, предупреждения и ошибки. Приемка: второй материал связан только обоснованным идентификатором; SSRF и разрыв маршрута проверены.
4. **D / измерение.** 40 dev + 80 test, >=30 изображений, раздельные семейства/домены, фиксированные веса, три варианта. Приемка: реальные JSON/CSV, интервалы Wilson, coverage, p50/p95, ошибки и ограничения в UI.
5. **E / демонстрация.** Typecheck/lint/backend/build, настоящий браузер, Windows setup/start, offline и перезапуск, экспорт, пятиминутный питч. Приемка: воспроизводимые команды и доказательства фактически выполненных проверок.

Следующий этап начинается после исправления ошибок основного сценария. Публикация, платные ресурсы и удаленный репозиторий не предусмотрены.

## Исторический итог первоначальной v1

- [x] A: CPU OCR по пикселям, синтетический маршрут, SDK/schema/errors. Живой Gemini не проверен без ключа.
- [x] B: новый ввод через браузер, reload и реальный перезапуск, проверенный скачанный ZIP.
- [x] C: второй материал, evidence стрелки, предупреждение/новость, частичный результат, провайдер и SSRF.
- [x] D: 40/80, 41 изображение, test зафиксирован, ошибки и реальные показатели сохранены. Цели precision/recall не достигнуты.

Аудит требований — `reports/ACCEPTANCE.md`. Дополнительные QR/видео/сравнение маршрутов остаются в roadmap.


## Текущее завершение v3

Этапы A–E сохранены и расширены: QR, сравнение наблюдений, индекс конкретного материала, защита очереди/оригиналов, полное резервирование, управляемый запуск, восстановление моделей и проверенный перенос. Полный итоговый прогон:270 Python-тестов,21 frontend-тест; typecheck/lint/build/preflight прошли. Живой Gemini, Linux и GPU не проверены.

После фиксации rules-3.0 создан отдельный test-v3:80 авторских синтетических случаев,32 изображения; precision96,97%, recall80%, FPR2,5%, coverage69/80. Семь положительных отказов входят в FN. Это не независимая оценка реальных соцсетей; широкие интервалы и девять ошибок опубликованы. Короткое видео и независимый пилот остаются дорожной картой.
