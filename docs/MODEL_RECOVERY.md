# Восстановление моделей OCR

Если preflight сообщает отсутствующий файл или неверный хеш модели, обычная проверка не должна объявлять установку готовой. Восстановление выполняется отдельно и не меняет закрепленные веса или manifest.

Остановите работающий сервер командой `powershell -ExecutionPolicy Bypass -File .\scripts\stop.ps1` либо Ctrl+C в его терминале. Дождитесь окончания или отмените активный анализ. Затем из корня проекта:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_models.py --repair
.\.venv\Scripts\python.exe scripts\preflight.py
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1 -Offline -Background
```

Сначала проверяется локальный кэш Paddle. Если он не соответствует закрепленным хешам, скрипт скачивает модель из официального источника и проверяет все файлы во временной папке. Неверное содержимое не заменяет установленную модель. Без подходящего кэша для восстановления нужен интернет; обычный анализ после установки остается офлайн.

Только после успешной проверки неполная прежняя папка переносится в `models/.replaced-<имя>-<id>`, а проверенная копия занимает ее место. Путь сохраненной папки выводится в терминале. При ошибке установки после этого переноса скрипт пытается вернуть прежнюю папку. Корректные модели не переписываются. Не запускайте несколько установок или восстановлений одновременно.

Без `--repair` существующая поврежденная папка остается на месте, а сообщение предлагает точную команду. Отсутствующий `models-manifest.json` не создается заново из произвольных скачанных файлов: восстановите его из той же версии исходников проекта. Для Windows полный путь проекта должен содержать ASCII-символы; пробелы допустимы.

Проверки включают прерванную копию, неверный кэш, несовпавшие хеши загрузки, сбой установки каталога, ссылки и неоднозначные пути в TAR. [Отчет о восстановлении](../reports/acceptance-v3/model-recovery-check.json).
